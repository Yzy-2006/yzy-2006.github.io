## Pandas 基本语法总结

Pandas 是 Python 中常用的数据分析库，主要用于处理表格数据。

Pandas 中最重要的两种数据结构是：

```text
Series：一维带标签的数据
DataFrame：二维表格数据
```

在机器学习中，Pandas 经常用于读取数据、查看数据、筛选样本、处理缺失值、构造特征以及划分特征和标签。

一般导入方式为：

```python
import pandas as pd
```

这里的 `pd` 是 `pandas` 的简写，之后可以通过 `pd.xxx()` 调用 Pandas 中的函数。

通常也会同时导入 NumPy：

```python
import numpy as np
import pandas as pd
```

---

## 创建 Series

`Series` 可以理解为一列带有索引的数据。

### 从列表创建 Series

```python
s = pd.Series([80, 90, 75])
print(s)
```

输出：

```text
0    80
1    90
2    75
dtype: int64
```

左边是索引，右边是数据。

---

### 指定索引

```python
s = pd.Series(
    [80, 90, 75],
    index=["张三", "李四", "王五"]
)

print(s)
```

输出：

```text
张三    80
李四    90
王五    75
dtype: int64
```

通过索引可以取得对应的数据：

```python
s["李四"]
```

结果为：

```python
90
```

## 创建 DataFrame

`DataFrame` 可以理解为一张带有行索引和列名的二维表格。

### 从字典创建 DataFrame

```python
data = {
    "name": ["张三", "李四", "王五", "赵六"],
    "age": [18, 20, 19, 21],
    "score": [85.0, 92.0, 76.0, 88.0],
    "city": ["北京", "上海", "北京", "广州"]
}

df = pd.DataFrame(data)
print(df)
```

输出：

```text
  name  age  score city
0   张三   18   85.0   北京
1   李四   20   92.0   上海
2   王五   19   76.0   北京
3   赵六   21   88.0   广州
```

其中：

```text
0、1、2、3                  → 行索引
name、age、score、city      → 列名
```

---

### 从二维列表创建 DataFrame

```python
df = pd.DataFrame(
    [
        ["张三", 18, 85.0],
        ["李四", 20, 92.0],
        ["王五", 19, 76.0]
    ],
    columns=["name", "age", "score"]
)
```

`columns` 用于指定每一列的列名。

## 选择列

### 选择一列

```python
df["score"]
```

结果是一个 `Series`。

也可以写成：

```python
df.score
```

但是更推荐使用：

```python
df["score"]
```

因为这种写法不受空格、特殊字符和方法重名的影响。

---

### 选择多列

```python
df[["name", "score"]]
```

注意需要使用两层中括号：

```text
外层中括号：从 DataFrame 中选择数据
内层中括号：列名组成的列表
```

结果仍然是一个 `DataFrame`。

## 使用 loc 选择数据

`loc` 根据行标签和列名选择数据。

基本格式为：

```python
df.loc[行, 列]
```

### 选择一行

```python
df.loc[0]
```

表示选择索引标签为 `0` 的行。

---

### 选择指定行和列

```python
df.loc[0, "name"]
```

结果为：

```text
张三
```

选择多行多列：

```python
df.loc[[0, 2], ["name", "score"]]
```

---

### 使用标签切片

```python
df.loc[0:2, "name":"score"]
```

需要注意，`loc` 的标签切片通常包含结束位置。

因此：

```python
df.loc[0:2]
```

会选择索引标签 `0`、`1`、`2` 对应的三行。

---

## 使用 iloc 选择数据

`iloc` 根据整数位置选择数据，使用方式和 NumPy 索引类似。

基本格式为：

```python
df.iloc[行位置, 列位置]
```

### 选择一个元素

```python
df.iloc[0, 2]
```

表示选择第 1 行、第 3 列的数据。

Python 的位置索引从 `0` 开始。

---

### 使用位置切片

```python
df.iloc[:3, :2]
```

表示：

```text
选择前 3 行
选择前 2 列
```

与普通 Python 切片相同，`iloc` 切片不包含结束位置。

## 条件筛选

### 单个条件

筛选成绩不低于 85 分的数据：

```python
df[df["score"] >= 85]
```

其中：

```python
df["score"] >= 85
```

会生成一个布尔值 `Series`：

```text
0     True
1     True
2    False
3     True
Name: score, dtype: bool
```

再用这个布尔值 `Series` 从原表中选择满足条件的行。

---

### 多个条件

筛选年龄不低于 19 岁并且成绩不低于 85 分的数据：

```python
df[(df["age"] >= 19) & (df["score"] >= 85)]
```

筛选来自北京或者上海的数据：

```python
df[(df["city"] == "北京") | (df["city"] == "上海")]
```

其中：

```text
&    并且
|    或者
~    取反
```

每个条件都需要使用小括号括起来。

不能直接使用 Python 的 `and` 和 `or` 连接两个 `Series` 条件。

---

### isin

筛选某一列属于多个指定值的数据：

```python
df[df["city"].isin(["北京", "上海"])]
```

排除这些值：

```python
df[~df["city"].isin(["北京", "上海"])]
```

---

### between

筛选成绩在 80 到 90 分之间的数据：

```python
df[df["score"].between(80, 90)]
```

默认包含 80 和 90。

---

### query

也可以使用字符串表达式筛选：

```python
df.query("age >= 19 and score >= 85")
```

如果需要引用 Python 变量，可以在变量名前加 `@`：

```python
min_score = 85
df.query("score >= @min_score")
```

## 修改和新增列

### 修改一列

```python
df["score"] = df["score"] + 5
```

这会给 `score` 列的每一个值加 5。

---

### 新增一列

```python
df["passed"] = df["score"] >= 60
```

结果中的 `passed` 列为布尔值：

```text
True     及格
False    不及格
```

根据现有列计算新特征：

```python
df["score_ratio"] = df["score"] / 100
```

---

### 使用 assign

`assign()` 会返回一个新的 `DataFrame`：

```python
new_df = df.assign(
    passed=df["score"] >= 60,
    score_ratio=df["score"] / 100
)
```

原来的 `df` 不会被修改。

---

### 根据条件赋值

把不及格成绩统一改为 60：

```python
df.loc[df["score"] < 60, "score"] = 60
```

推荐使用 `loc` 同时指定行和列，避免链式赋值问题。

## 处理缺失值

缺失值通常显示为：

```text
NaN
None
NaT
```

### 检查缺失值

```python
df.isna()
```

统计每一列的缺失值数量：

```python
df.isna().sum()
```

统计整个表的缺失值总数：

```python
df.isna().sum().sum()
```

`isnull()` 和 `isna()` 的作用相同：

```python
df.isnull()
```

---

### 删除缺失值

删除含有缺失值的行：

```python
df = df.dropna()
```

只在指定列缺失时删除该行：

```python
df = df.dropna(subset=["score"])
```

删除所有值都缺失的行：

```python
df = df.dropna(how="all")
```

---

### 填充缺失值

使用固定值填充：

```python
df["city"] = df["city"].fillna("未知")
```

使用平均值填充数值列：

```python
df["score"] = df["score"].fillna(df["score"].mean())
```

使用中位数填充：

```python
df["age"] = df["age"].fillna(df["age"].median())
```

在存在极端值时，中位数通常比平均值更加稳定。

使用前一个有效值填充：

```python
df["score"] = df["score"].ffill()
```

使用后一个有效值填充：

```python
df["score"] = df["score"].bfill()
```

## 字符串处理

Pandas 可以通过 `.str` 对一列字符串进行处理。

去除字符串两端的空格：

```python
df["name"] = df["name"].str.strip()
```

转换为小写：

```python
df["city"] = df["city"].str.lower()
```

判断是否包含指定文字：

```python
df[df["name"].str.contains("张", na=False)]
```

替换字符串：

```python
df["city"] = df["city"].str.replace("市", "", regex=False)
```

拆分字符串：

```python
df[["province", "city"]] = df["address"].str.split(
    "-",
    n=1,
    expand=True
)
```

## 日期时间处理

把字符串转换为日期时间：

```python
df["date"] = pd.to_datetime(df["date"])
```

如果可能存在错误数据：

```python
df["date"] = pd.to_datetime(df["date"], errors="coerce")
```

提取日期信息：

```python
df["year"] = df["date"].dt.year
df["month"] = df["date"].dt.month
df["day"] = df["date"].dt.day
df["weekday"] = df["date"].dt.dayofweek
```

其中：

```text
dayofweek 为 0 表示星期一
dayofweek 为 6 表示星期日
```

计算两个日期之间的时间差：

```python
df["days"] = (df["end_date"] - df["start_date"]).dt.days
```

## map 和 apply

### 使用 map 替换一列中的值

```python
city_code = {
    "北京": 0,
    "上海": 1,
    "广州": 2
}

df["city_code"] = df["city"].map(city_code)
```

`map()` 常用于对 `Series` 中的每一个元素进行映射。

如果原数据中存在字典没有包含的值，映射结果会是 `NaN`。

---

### 使用 apply 调用函数

```python
def score_level(score):
    if score >= 90:
        return "优秀"
    elif score >= 60:
        return "及格"
    else:
        return "不及格"

df["level"] = df["score"].apply(score_level)
```

也可以使用匿名函数：

```python
df["score_ratio"] = df["score"].apply(lambda x: x / 100)
```

简单的数值运算应优先使用向量化写法：

```python
df["score_ratio"] = df["score"] / 100
```

这种写法通常比 `apply()` 更简洁、速度也更快。

## 分组统计

`groupby()` 用于按照某一列或多列对数据进行分组。

### 按一列分组

计算每个城市的平均成绩：

```python
df.groupby("city")["score"].mean()
```

如果希望结果仍然是 `DataFrame`：

```python
df.groupby("city", as_index=False)["score"].mean()
```

---

### 同时计算多个统计量

```python
result = df.groupby("city")["score"].agg(
    ["count", "mean", "max", "min"]
)
```

使用更清楚的列名：

```python
result = df.groupby("city").agg(
    student_count=("name", "count"),
    average_score=("score", "mean"),
    highest_score=("score", "max")
).reset_index()
```

---

### 按多列分组

```python
df.groupby(["city", "gender"])["score"].mean()
```

表示先按照城市分组，再在每个城市中按照性别分组。

---

### 使用 transform

为每一行添加所在城市的平均成绩：

```python
df["city_mean"] = df.groupby("city")["score"].transform("mean")
```

`agg()` 通常会减少数据行数，`transform()` 返回的结果则与原数据行数相同，因此可以直接作为新列加入原表。

## 合并数据

### concat

按行拼接两个结构相同的表：

```python
all_data = pd.concat(
    [train_df, test_df],
    axis=0,
    ignore_index=True
)
```

其中：

```text
axis=0             按行拼接
ignore_index=True  重新生成连续索引
```

按列拼接：

```python
new_df = pd.concat([feature_df, label_df], axis=1)
```

---

### merge

假设有两张表：

```python
students = pd.DataFrame({
    "student_id": [1, 2, 3],
    "name": ["张三", "李四", "王五"]
})

scores = pd.DataFrame({
    "student_id": [1, 2, 4],
    "score": [85, 92, 78]
})
```

按照 `student_id` 合并：

```python
result = pd.merge(
    students,
    scores,
    on="student_id",
    how="inner"
)
```

`how` 的常见取值：

```text
inner    只保留两个表中都存在的键
left     保留左表中的所有键
right    保留右表中的所有键
outer    保留两个表中的所有键
```

左连接：

```python
result = pd.merge(
    students,
    scores,
    on="student_id",
    how="left"
)
```

如果两个表用于连接的列名不同：

```python
result = pd.merge(
    left_df,
    right_df,
    left_on="student_id",
    right_on="id",
    how="left"
)
```

for chunk in pd.read_csv("large_data.csv", chunksize=10000):

## 在机器学习中准备特征和标签

### 使用 get_dummies 独热编码

## 一个完整的数据处理例子

假设原始文件 `students.csv` 中包含：

```text
name,age,score,city,passed
张三,18,85,北京,1
李四,20,92,上海,1
王五,19,,北京,0
赵六,21,88,广州,1
赵六,21,88,广州,1
```

完整处理过程：

```python
import pandas as pd
from sklearn.model_selection import train_test_split

# 1. 读取数据
df = pd.read_csv("students.csv")

# 2. 查看数据基本情况
print(df.head())
print(df.shape)
df.info()
print(df.isna().sum())

# 3. 删除重复行
df = df.drop_duplicates().reset_index(drop=True)

# 4. 转换数据类型
df["age"] = pd.to_numeric(df["age"], errors="coerce")
df["score"] = pd.to_numeric(df["score"], errors="coerce")

# 5. 处理缺失值
df["age"] = df["age"].fillna(df["age"].median())
df["score"] = df["score"].fillna(df["score"].median())
df["city"] = df["city"].fillna("未知")

# 6. 构造新特征
df["score_ratio"] = df["score"] / 100

# 7. 对分类变量进行独热编码
df = pd.get_dummies(
    df,
    columns=["city"],
    dtype=int
)

# 8. 选择特征和标签
x = df.drop(columns=["name", "passed"])
y = df["passed"]

# 9. 划分训练集和测试集
x_train, x_test, y_train, y_test = train_test_split(
    x,
    y,
    test_size=0.2,
    random_state=42
)

print(x_train.shape)
print(x_test.shape)
```

这个例子完成了：

```text
1. 读取 CSV 文件
2. 查看数据基本信息
3. 删除重复数据
4. 转换数据类型
5. 填充缺失值
6. 构造新特征
7. 编码分类变量
8. 分离特征和标签
9. 划分训练集和测试集
```

## 常见注意事项

### Pandas 操作通常按照索引对齐

```python
s1 = pd.Series([10, 20], index=["a", "b"])
s2 = pd.Series([1, 2], index=["b", "a"])

print(s1 + s2)
```

结果为：

```text
a    12
b    21
dtype: int64
```

Pandas 会按照索引标签对齐后再计算，而不是简单地按照位置计算。

---

### count 和 size 的区别

```python
df["score"].count()
```

只统计非空值数量。

```python
df["score"].size
```

统计所有元素数量，包括缺失值。

---

### 筛选后索引可能不连续

```python
result = df[df["score"] >= 85]
```

筛选结果会保留原来的索引。

如果需要连续索引：

```python
result = result.reset_index(drop=True)
```

---

### 不要默认修改原数据

很多 Pandas 方法会返回一个新对象，而不会直接修改原数据：

```python
df.dropna()
df.sort_values("score")
df.reset_index()
```

因此通常需要重新赋值：

```python
df = df.dropna()
df = df.sort_values("score")
df = df.reset_index(drop=True)
```
