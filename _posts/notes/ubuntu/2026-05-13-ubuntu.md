## 一些乱七八糟的奇技淫巧

### 打开Ubuntu变成老式雪花屏了怎么办？

不要慌，这时候一般是NVIDIA这老小子的显卡驱动出问题了，通常系统会提示我们进行更新，如果没有的话，可以尝试打开"软件和更新"换一个驱动一般就好了。

### 如何把webm转成mp4

使用我们亲爱滴`ffmpeg`

```bash
sudo apt update
sudo apt install ffmpeg
```

```bash
ffmpeg -i input.webm \
  -c:v libx264 -crf 23 -preset medium \
  -c:a aac -b:a 128k \
  -movflags +faststart \
  output.mp4
```

### 实时查看GPU的工作状态

```bash
watch -n 0.5 'nvidia-smi --query-gpu=utilization.gpu,memory.used,power.draw,temperature.gpu --format=csv,noheader'
```

### 可以切分的终端

有时候一个任务需要多个终端的话用系统自带的终端可能不太方便，所以我们使用`terminator`

```bash
sudo apt update
sudo apt install terminator
```
