**如何在Linux里边打出罗马数字?**
```
Ctrl + Shift + u
2160
Enter

2160 = Ⅰ
2161 = Ⅱ
2162 = Ⅲ
2163 = Ⅳ
2164 = Ⅴ
2165 = Ⅵ
2169 = Ⅹ
2170 = ⅰ
2171 = ⅱ
```

**打开Ubuntu变成老式雪花屏了怎么办？**

不要慌，这时候一般是NVIDIA这老小子的显卡驱动出问题了，通常系统会提示我们进行更新，如果没有的话，可以尝试打开"软件和更新"换一个驱动一般就好了。
