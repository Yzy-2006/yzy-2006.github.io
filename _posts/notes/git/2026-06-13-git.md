## 1.子模块(submodule)
 
### 1.1 克隆仓库时同时初始化子模块

```bash
git clone --recurse-submodules <仓库地址>
```

### 1.2 如果仓库已经克隆但是当时没有初始化子模块

```bash
git submodule update --init --recursive
```

### 1.3 拉取最新的提交时

```bash
git pull --recurse-submodules
git submodule update --init --recursive
```

>--init的作用是注册并初始化子模块配置，针对没有初始化过的子模块
{: .prompt-info}

### 1.4 默认递归处理子模块

```bash
git config --global submodule.recurse true
```

>只针对于已经初始化了的子模块
{: .prompt-info}
