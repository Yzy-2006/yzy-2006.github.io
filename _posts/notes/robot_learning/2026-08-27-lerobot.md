## 一、安装

[官方文档](https://huggingface.co/docs/lerobot/main/en/installation?install_lerobot_src=conda&cuda_variant=uv-source)

```bash
# 创建名为 lerobot 的独立 Conda 环境，并在其中安装 Python 3.12；-y 表示自动确认。
conda create -y -n lerobot python=3.12
# 激活刚创建的环境，后续依赖都会安装到该环境中。
conda activate lerobot

# 从 conda-forge 安装 FFmpeg，用于 LeRobot 录制、读取和编码视频。
conda install -c conda-forge ffmpeg

# 从 PyTorch 官方的 CUDA 12.8 软件源安装 PyTorch 与 torchvision。
# 需要 NVIDIA 显卡及兼容的驱动；反斜杠表示这条命令在下一行继续。
pip install --index-url https://download.pytorch.org/whl/cu128 \
    torch torchvision

# 创建项目目录（目录已存在时不报错），并进入该目录。
mkdir -p ~/projects
cd ~/projects

# 克隆 LeRobot 源码仓库，并进入仓库根目录。
git clone https://github.com/huggingface/lerobot.git
cd lerobot

# 以可编辑模式安装当前源码，并安装 all extra 中包含的可选功能依赖。
# 此后修改当前仓库的 Python 代码无需重新安装即可生效。
pip install -e ".[all]"

# 输出 LeRobot、Python、PyTorch 和设备等环境信息，用于确认安装是否成功。
lerobot-info
```

其中，`-n lerobot` 指定 Conda 环境名，`-c conda-forge` 指定 FFmpeg 的软件源。`--index-url` 将 PyTorch 的下载源切换为 CUDA 12.8 预编译包；如果只使用 CPU 或 CUDA 版本不匹配，应改用相应的 PyTorch 安装命令。

`pip install -e ".[all]"` 中的 `.` 表示当前 LeRobot 仓库，`-e` 表示可编辑安装，`[all]` 表示一并安装项目定义的全部可选依赖。

## 二、Lerobot的最小工作流程

### 1. 使用命令行对一个数据集进行可视化

```bash
lerobot-dataset-viz \
    --repo-id lerobot/pusht \

```

#### 数据集下载时出现代理配置问题

在下载数据集时出现`ValueError: Unknown scheme for proxy URL URL('socks://127.0.0.1:7897/')`，这时候应该是梯子修改了我们系统的环境变量，我们只需要关闭一下即可，同时为了不每次打开终端都要设置，我们直接把他写到`lerobot`这个conda环境的启动脚本中

```bash
conda activate lerobot

mkdir -p "$CONDA_PREFIX/etc/conda/activate.d"

cat > "$CONDA_PREFIX/etc/conda/activate.d/proxy_fix.sh" <<'EOF'
#!/bin/bash
unset ALL_PROXY
unset all_proxy
EOF

```

### 2.使用python加载数据集

```py
from lerobot.datasets import LeRobotDataset

dataset = LeRobotDataset("lerobot/pusht")
sample = dataset[0]

print("数据集帧数:", len(dataset))
print("样本字段:", sample.keys())
print("状态:", sample["observation.state"])

```

### 3.使用DataLoader提取一个batch的数据

```py
from torch.utils.data import DataLoader

from lerobot.datasets import LeRobotDataset

dataset = LeRobotDataset("lerobot/pusht")
dataloader = DataLoader(dataset, batch_size=8)
batch = next(iter(dataloader))

print("状态批次形状:", batch["observation.state"].shape)
print("动作批次形状:", batch["action"].shape)
```

### 4.构建delta_timestamps

`delta_timestamps` 用于为当前帧同时读取指定时间偏移的观测或动作，从而构造带时间上下文的样本。

```py
from lerobot.datasets import LeRobotDataset

delta_timestamps = {
    "observation.image": [-0.2, -0.1, 0.0],
    "observation.state": [-0.2, -0.1, 0.0],
    "action": [0.0, 0.1, 0.2, 0.3, 0.4],
}

dataset = LeRobotDataset(
    "lerobot/pusht",
    delta_timestamps=delta_timestamps,
)
sample = dataset[0]

print("图像序列形状:", sample["observation.image"].shape)
print("状态序列形状:", sample["observation.state"].shape)
print("动作序列形状:", sample["action"].shape)
```

负值表示读取当前帧之前的数据，`0.0` 表示当前帧，正值表示读取之后的数据。上述配置会为图像和状态各读取 3 个时刻，为动作读取当前及之后的 5 个时刻。

**Observation Horizon：** Policy 一次看多少个时间步的 Observation

**Action Horizon：** Policy 一次预测多少个时间步的 Action

### 5.开始训练

#### CLI版本

```bash
lerobot-train \
    --dataset.repo_id=lerobot/pusht \
    --policy.type=act \
    --policy.device=cuda \
    --policy.push_to_hub=false \
    --batch_size=32 \
    --steps=5000 \
    --save_checkpoint=true \
    --save_freq=1000 \
    --log_freq=50 \
    --wandb.enable=false \
    --output_dir=outputs/train/act_pusht \
    --job_name=act_pusht
```

#### 参数说明

- `--dataset.repo_id`：训练数据集的 Hugging Face 仓库 ID。
- `--policy.type=act`：选择 ACT 策略；模型的输入、输出特征会根据数据集自动配置。
- `--policy.device=cuda`：使用 NVIDIA GPU 训练；也可改为 `cpu` 或 `mps`。
- `--policy.push_to_hub=false`：训练结束后不自动将模型上传到 Hugging Face Hub。
- `--batch_size=32`：每个训练批次包含的样本数。
- `--steps=5000`：优化器更新的总步数。
- `--save_checkpoint=true`：启用 checkpoint 保存。
- `--save_freq=1000`：每训练 1000 步保存一次 checkpoint。
- `--log_freq=50`：每训练 50 步输出一次训练日志。
- `--wandb.enable=false`：关闭 Weights & Biases 实验记录。
- `--output_dir`：训练日志、checkpoint 和最终模型的保存目录。
- `--job_name`：本次训练任务的名称，用于日志和实验追踪。

#### Python版本

```py
from pathlib import Path

from lerobot.configs import DatasetConfig, WandBConfig
from lerobot.configs.train import TrainPipelineConfig
from lerobot.policies.factory import make_policy_config
from lerobot.scripts.lerobot_train import train

cfg = TrainPipelineConfig(
    dataset=DatasetConfig(repo_id="lerobot/pusht"),
    policy=make_policy_config("act", device="cuda", push_to_hub=False),
    output_dir=Path("outputs/train/act_pusht"),
    job_name="act_pusht",
    batch_size=32,
    steps=5000,
    log_freq=50,
    save_checkpoint=True,
    save_freq=1000,
    wandb=WandBConfig(enable=False),
)
train(cfg)
```

### 6.评估模型

#### CLI版本

```bash
lerobot-eval \
    --policy.path=outputs/train/act_pusht/checkpoints/005000/pretrained_model \
    --env.type=pusht \
    --eval.batch_size=10 \
    --eval.n_episodes=10 \
    --policy.use_amp=false \
    --policy.device=cuda
```

#### 参数说明

- `--policy.path`：要评估的模型目录或 Hugging Face Hub 模型 ID；本例使用第 5000 步的 checkpoint。
- `--env.type=pusht`：指定 PushT 仿真环境。
- `--eval.batch_size=10`：并行运行 10 个仿真环境；它不等同于训练时的 batch size。
- `--eval.n_episodes=10`：运行 10 个评估回合，并据此统计评估指标。
- `--policy.use_amp=false`：关闭自动混合精度推理。
- `--policy.device=cuda`：在 NVIDIA GPU 上运行策略推理。

#### Python版本

```py
from pathlib import Path

from lerobot.configs import EvalConfig, PreTrainedConfig
from lerobot.configs.eval import EvalPipelineConfig
from lerobot.envs.factory import make_env_config
from lerobot.scripts.lerobot_eval import eval_main

checkpoint = Path("outputs/train/act_pusht/checkpoints/005000/pretrained_model")
policy = PreTrainedConfig.from_pretrained(checkpoint)
policy.pretrained_path = checkpoint
policy.device = "cuda"
policy.use_amp = False

cfg = EvalPipelineConfig(
    env=make_env_config("pusht"),
    policy=policy,
    eval=EvalConfig(batch_size=10, n_episodes=10),
)
eval_main(cfg)
```
