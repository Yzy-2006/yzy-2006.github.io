## 一、前身—π₀

### π₀ 简介

**π₀（pi-zero）是 Physical Intelligence 提出的通用视觉-语言-动作（VLA）机器人基础模型。**
它以约 **3B 参数的 PaliGemma VLM** 负责图像和语言理解，并增加约 **300M 参数的 Action Expert** 处理机器人状态与动作，两者通过 Transformer 的 **Self-Attention** 进行信息交互。与将动作离散化后逐 Token 预测的方法不同，π₀ 使用 **Flow Matching** 从随机噪声中生成连续的 **Action Chunk（H=50）**，从而结合 VLM 的语义理解能力与高频、连续的机器人控制能力。

### π₀ 结构

```text
              ┌───────────────────────┐
 图像 Images ─┤                       │
              │  PaliGemma VLM (~3B) │
 语言 Prompt ─┤   视觉 / 语言理解      │

                         │

                         │

          [aₜ, aₜ₊₁, ..., aₜ₊₄₉]

```

## 二、π₀.₅想要解决的问题—Open-World Generalization

**核心思想:** 先理解“接下来应该做什么”，再决定“机械臂具体怎么动”，并通过大量不同类型的数据训练，让这种能力能够泛化到没见过的现实环境。


$$
\pi_{0.5} = \mathrm{VLA} + \text{高层任务规划} + \text{低层连续控制} + \text{异构数据 Co-training} + \text{Open-World Generalization}
$$

## 三、High-Level 和 Low-Level

### High-Level Inference

比如输入：

```text
任务：

"clean the bedroom"

当前图像：

床上少了一个枕头
地上有枕头
```

模型输出：

```text
"pick up the pillow"
```

这是一个：

> **Semantic Subtask，语义子任务。**

然后第二阶段：

### Low-Level Inference

模型再根据：

```text
图像
+
机器人状态
+
"pick up the pillow"
```

生成真正的连续动作：

```text
机械臂向下
↓
移动到枕头
↓
调整腕部
↓
夹爪张开
↓
抓住枕头
↓
抬起来
```

## 四、Co-training

训练数据不完全是机器人动作

```text
                π₀.₅ Training Data
                        │
          ┌─────────────┼─────────────┐
          │             │             │
   Robot Action      Language       Web Data
       Data            Data
          │             │             │
          ▼             ▼             ▼
     移动机器人       子任务预测       Captioning
     固定机械臂       人类语言指导     VQA
     多机器人数据     Task Planning   Object Detection
     实验室数据                     Object Localization
```

也就是说：

> **机器人不会只从机器人动作中学习机器人。**

它还可以从：

- 图片描述
- VQA
- 目标检测
- 语言
- 人类任务规划
- 其他机器人的动作

中学习有用知识。
